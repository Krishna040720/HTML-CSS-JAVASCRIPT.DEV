## 🎯 Aim / Objective
To design and customize the online bookstore interface using advanced **CSS Selectors, Typography, Colors, and Background Images**:
1. **Font & Style Variety:** Use different fonts (`Georgia`, `Verdana`, `"Courier New"`, `Arial`), font sizes, weights, and letter spacing across selectors.
2. **Page Background Image:** Set a repeating background pattern (`bg_page.png`) for the overall `<body>` with a crisp container overlay (`.login-page`).
3. **Single Element Background:** Set a specialized banner graphic (`bg_title.png`) for the `.login-title` container.
4. **Targeted Selectors:** Implement class selectors, ID selectors, and contextual combinators.
