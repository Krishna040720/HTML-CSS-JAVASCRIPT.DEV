## 🎯 Aim / Objective
To design and implement a structured **Catalogue Page** for an Online Book Store using HTML tables and CSS styling.

### Required Details for Each Item:
1. **Department identifier:** CSE, ECE, EEE, CIVIL.
2. **Snapshot of Cover Page:** Image of the book cover.
3. **Book Details:** Title, Author Name, Publisher Name.
4. **Price:** Price in Indian Rupees (₹).
5. **Add to Cart Button:** Interactive button with custom styling and hover state.
