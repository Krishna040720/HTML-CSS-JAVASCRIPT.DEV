## 📚 Overview of Experiments

### 1. [Experiment 1: Online Book Store — Homepage](./EXP%201/)
- **Aim:** Design a multi-frame static homepage for an online book store.
- **Tech Stack:** HTML5 Framesets (`<frameset>`, `<frame>`), CSS3.
- **Highlights:** Top navigation frame, left department categories (*CSE, ECE, EEE, CIVIL, MECHANICAL*), and right target frame.

### 2. [Experiment 2: Clean Login Page](./EXP%202/)
- **Aim:** Design a login portal embedded in the book store table structure.
- **Tech Stack:** HTML Tables, Pure CSS `:target` pseudo-class routing.
- **Highlights:** Zero-JavaScript client-side tab switching between Home, Login, Registration, Catalogue, and Cart.

### 3. [Experiment 3: Catalogue Page](./EXP%203/)
- **Aim:** Build a product catalogue table listing textbooks across engineering branches.
- **Tech Stack:** HTML Tables, CSS styling, custom buttons with hover states.
- **Highlights:** Book cover snapshots, author, publisher, INR pricing (₹), and styled Add to Cart buttons.

### 4. [Experiment 4: Cart Page](./EXP%204/)
- **Aim:** Build an itemized checkout and order review table for items added to the cart.
- **Tech Stack:** HTML Tables, CSS column styling and alignment.
- **Highlights:** Itemized lines for each textbook, unit price, quantity, total amount, and grand total (`- ₹2100`).

### 5. [Experiment 5: Registration Page](./EXP%205/)
- **Aim:** Create a complete registration form with all required form controls.
- **Tech Stack:** HTML5 Form elements, CSS table layout.
- **Highlights:** Text fields, password field, radio buttons, DOB dropdown selects, language checkboxes, textarea, and submit/clear buttons.

### 6. [Experiment 6: JS Validation — Name & Password](./EXP%206/)
- **Aim:** Implement client-side JavaScript validation for Name and Password fields.
- **Tech Stack:** HTML5, CSS3, JavaScript (DOM Manipulation, Regex).
- **Highlights:** Verifies alphabets-only constraint (`/^[A-Za-z]+$/`) and minimum 6-character length with real-time border highlighting and alert dialogs.

### 7. [Experiment 7: JS Validation — Email & Phone](./EXP%207/)
- **Aim:** Implement client-side JavaScript validation for E-mail ID and Phone Number.
- **Tech Stack:** HTML5, CSS3, JavaScript (Regex Pattern Matching).
- **Highlights:** Validates standard email structure (`name@domain.com`) and strictly 10-digit numeric phone numbers (`/^[0-9]+$/`).

### 8. [Experiment 8: CSS — Selectors, Fonts & Backgrounds](./EXP%208/)
- **Aim:** Use different fonts and styles through CSS selectors, and apply background images.
- **Tech Stack:** CSS3 (Class & ID selectors, Font properties, Background images).
- **Highlights:** Page background pattern (`bg_page.png`), title bar background (`bg_title.png`), and custom typography per selector.

### 9. [Experiment 9: CSS — Background Repeat & Link States](./EXP%209/)
- **Aim:** Control image repetition with `background-repeat` and define hyperlink state styles.
- **Tech Stack:** CSS3 (`background-repeat`, `:link`, `:visited`, `:hover`, `:active`).
- **Highlights:** `repeat` vs `repeat-x` controls, along with the standard *LoVe HAte* pseudo-class sequence.
