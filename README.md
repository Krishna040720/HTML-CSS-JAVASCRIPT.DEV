## 📚 Overview of Experiments

### 1. [Experiment 1: Online Book Store — Homepage](./EXP%201/)
- **Aim:** Design a multi-frame static homepage for an online book store.
- **Tech Stack:** HTML5 Framesets (`<frameset>`, `<frame>`), CSS3.
- **Highlights:** 
  - Top navigation frame (`top.html`) with GL Bajaj emblem, titles, and links.
  - Left navigation frame (`left.html`) with department categories (*CSE, ECE, EEE, CIVIL, MECHANICAL*).
  - Target content frame (`welcome.html` & department catalogues) loaded inside `rightFrame`.

### 2. [Experiment 2: Clean Login Page](./EXP%202/)
- **Aim:** Design a login portal embedded in the book store table structure.
- **Tech Stack:** HTML Tables, Pure CSS `:target` pseudo-class routing.
- **Highlights:** 
  - Zero-JavaScript client-side tab switching between Home, Login, Registration, Catalogue, and Cart.
  - Pixel-perfect table grid matching the lab manual specifications.

### 3. [Experiment 3: Catalogue Page](./EXP%203/)
- **Aim:** Build a product catalogue table listing textbooks across engineering branches.
- **Tech Stack:** HTML Tables, CSS styling, custom buttons with hover states.
- **Highlights:** 
  - Displays cover snapshots, book title, author, publisher, price in Indian Rupees (₹).
  - Styled "Add to Cart" call-to-action buttons.

### 4. [Experiment 4: Cart Page](./EXP%204/)
- **Aim:** Build an itemized checkout and order review table for items added to the cart.
- **Tech Stack:** HTML Tables, CSS column styling and alignment.
- **Highlights:** 
  - Clear breakdown of department, book title, unit price, quantity, and total amount.
  - Summary row calculating grand total (`- ₹2100`).

## 🛠️ How to Enable GitHub Pages (To View Live Links)

If not already enabled for this repository, follow these 3 quick steps:
1. Go to repository **Settings** on GitHub: `https://github.com/Krishna040720/HTML-CSS-JAVASCRIPT.DEV/settings/pages`.
2. Under **Build and deployment** > **Source**, choose **Deploy from a branch**.
3. Under **Branch**, select `main` branch and `/ (root)` folder, then click **Save**.
4. Your site will be live at:  
   👉 **`https://krishna040720.github.io/HTML-CSS-JAVASCRIPT.DEV/`**
