## 🎯 Aim / Objective
To design and develop a comprehensive **Registration Form** for the Online Book Store using HTML form controls and CSS table styling.

### Input Fields & Controls:
1. **Name:** Text field (`<input type="text">`)
2. **Password:** Password field (`<input type="password">`)
3. **E-mail id:** Text field (`<input type="text">`)
4. **Phone Number:** Text field (`<input type="text">`)
5. **Sex:** Mutually exclusive radio buttons (`<input type="radio">` for Male and Female)
6. **Date of Birth:** 3 select dropdown boxes (`<select>` for Day, Month, and Year)
7. **Languages Known:** Checkboxes (`<input type="checkbox">` for English, Telugu, Hindi, Tamil)
8. **Address:** Multi-line text area (`<textarea rows="4" cols="30">`)
9. **Action Buttons:** Form submit (`Register`) and form reset (`Clear`)
