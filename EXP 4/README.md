## 🎯 Aim / Objective
To design and implement an itemized **Shopping Cart Page** for an Online Book Store using HTML tables and CSS layout.

### Specifications:
1. **Header row:** GL Bajaj logo and website title (*GL Bajaj Online Store*).
2. **Navigation menu:** Home, Login, Registration, Catalogue, Cart.
3. **Cart table columns:**
   - Department identifier (*CSE, ECE, EEE, CIVIL*).
   - Book Name.
   - Unit Price (₹).
   - Quantity.
   - Total Amount per line item (₹).
4. **Summary row:** Displays the calculated Total Amount for all ordered books (`- ₹2100`).

### Itemized Summary Table:
| Department | Book Name | Unit Price | Quantity | Amount |
| :--- | :--- | :---: | :---: | :---: |
| **CSE** | Data Structures Using C | ₹550 | 1 | ₹550 |
| **ECE** | Electronic Devices and Circuits | ₹620 | 1 | ₹620 |
| **EEE** | Basic Electrical Engineering | ₹480 | 1 | ₹480 |
| **CIVIL** | Strength of Materials | ₹450 | 1 | ₹450 |
| **Total** | **Total amount** | **- ₹2100** | | |
