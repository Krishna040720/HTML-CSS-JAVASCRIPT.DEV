## 🎯 Aim / Objective
To design and customize the web page using advanced CSS background repetition and hyperlink state pseudo-classes:
1. **Background Repeat Control (`background-repeat`):**
   - Tile page background in both directions (`background-repeat: repeat;`).
   - Repeat header title background horizontally only (`background-repeat: repeat-x;`).
2. **Hyperlink Pseudo-Classes (LoVe HAte Order):**
   - `:link` (unvisited link): Navy blue text without underline.
   - `:visited` (previously visited link): Purple text without underline.
   - `:hover` (mouse pointer hovering): Crimson text with underline and `#fff3e0` background highlight.
   - `:active` (moment of being clicked): Orange text with underline and overline.
