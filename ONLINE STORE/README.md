## 🎯 About The Project
The **ONLINE STORE** is a comprehensive, production-grade web application that merges all 9 laboratory experiments from the Web Designing Workshop curriculum into a cohesive, interactive system.

### Integrated Laboratory Modules:
1. **Experiment 1 (Homepage Layout & Navigation):** Master branding with the official GL Bajaj crest, college titles, top navigation bar, and departmental branch category sidebar.
2. **Experiment 2 (Login Interface):** Clean table-based login portal with client-side credential verification and session management.
3. **Experiment 3 (Book Catalogue):** Dynamic academic textbook catalogue showcasing book covers, authors, publishers, prices in Indian Rupees (₹), and functional **"Add to Cart"** triggers.
4. **Experiment 4 (Interactive Shopping Cart):** Real-time shopping cart calculation with itemized book lines, unit pricing, quantity adjusters (`+` and `-`), line subtotals, item removal, and grand total sum (`- ₹2100` / dynamic total) with checkout processing.
5. **Experiment 5 (Comprehensive Registration Form):** Complete HTML form incorporating text inputs, password masking, gender radio buttons, 3-tier DOB dropdown selectors, language checkboxes, and multi-line address textareas.
6. **Experiment 6 & 7 (JavaScript Validation Engine):** Robust real-time client-side validation for Name (alphabets only, min 6 chars), Password (min 6 chars), Email ID (strict standard regex pattern `name@domain.com`), and Phone Number (strictly 10 numeric digits) with dynamic visual state feedback (`.good` green / `.bad` red) and alert dialogues.
7. **Experiment 8 (CSS Typography & Background Imagery):** Visual styling integrating `Georgia`, `Verdana`, and `"Courier New"` font families, page background pattern (`bg_page.png`), and container title banners (`bg_title.png`).
8. **Experiment 9 (CSS Background Repetition & Link States):** `background-repeat: repeat` and `background-repeat: repeat-x` combined with the standard *LoVe HAte* hyperlink pseudo-class sequence (`:link`, `:visited`, `:hover`, `:active`).
